- **Flows (all complete):** (a) CLI and MCP text are identical for log, log --with-prompts, show --with-prompts, show, diff (both forms), blame, cost, cost --all, including `Tool summary:`, with the MCP server run under `FORCE_COLOR=1`; (b) an out-of-range turn returns `isError` with the CLI text and later calls still work; (c) `cost --all` across two sessions prints one block per session plus a grand total, and the MCP result matches; (d) `git turn mcp` in a never-initialized repo prints the exact message and exits 1.
- **Orphans:** none.
- **Tests:** `npm test` passed 351/351 (339 main suite + 12 `mcp.test.js`, run in its own pass).

## Tech debt: where to look first

Nothing below blocks the milestone. In rough priority order if you want to clear some of it:

1. **Phase 8 WR-03 / WR-04** (`mcp.js`): no try/catch around `serveStdio()`, and no bounded fallback if `handle.close()` hangs on SIGINT. These are the only items on the long-running server path.
2. **Phase 8 WR-01** (`cost.js`): the `head_sha || snapshot_sha` fallback is used as a notes-lookup key. This is the exact bug class that shipped twice before (v0.2, v0.3), so it is worth fixing even though no current path triggers it.
3. **Phase 7 WR-01 / WR-03 / WR-04**: NaN in cost totals, a `RangeError` on huge diffs, and the colon-in-filename blame bug. Real but edge-case.
4. **Cosmetic and bookkeeping:** `--help` text (T1), stale comment (T2), 08-VERIFICATION.md `human_needed` status, and 09-01-SUMMARY empty `requirements-completed`. T1, T2 and the two bookkeeping items are one-line changes.

Backlog todos unrelated to this milestone are unchanged: mindwalk integration, stable change-identity research, Claude Code Stop-hook for `record-prompt`, `install-global-hook`, and a stale `cost --all` todo that Phase 8 already resolved and that should be closed.
