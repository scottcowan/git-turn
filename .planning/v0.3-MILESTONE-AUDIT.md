## Tech Debt (non-blocking)

1. **`tool_summary` is write-only.** CAPTURE-04 only requires the field be attachable, which it is — captured and persisted correctly in both the note and the cache. But no current command (`show`/`log`/`cost`) displays it. Worth a small follow-up phase once there's a real caller producing this data.
2. **`log --no-cache`'s diff stat uses the wrong sha.** Found incidentally during the integration checker's live E2E run: `git diff --shortstat ${sha}^..${sha}` in the `--no-cache` fallback path uses the snapshot sha, not the resolved HEAD sha, producing an empty stat column where the cache-backed path shows real numbers. This is a different bug from the one fixed in Phase 6 (which was about *notes* lookup, not diff stats) — same class of defect (snapshot-sha vs head-sha confusion), different call site, not covered by this milestone's requirements. Worth a quick follow-up fix.

Neither item blocks the milestone — both are additive/cosmetic gaps discovered by verification working as intended, not regressions.
