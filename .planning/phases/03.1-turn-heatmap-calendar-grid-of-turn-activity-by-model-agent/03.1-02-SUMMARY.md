## Accomplishments

- `densityGlyph`/`densityAnsi` map density levels 0..4 to ASCII glyphs (` `, `.`, `:`, `+`, `#`) and a 256-color palette (`236, 22, 28, 34, 40`), each degrading gracefully on out-of-range input
- `renderGrid` assembles a 9-line output (month-label header, 7 weekday rows, legend) with every colored cell carrying its own reset — verified by an open/reset-count balance assertion on every rendered line (D-01, Pitfall 3)
- `renderMonthLabels` places month abbreviations at the correct column offsets while skipping any label that would land within 3 columns of the previous one
- `renderSummary` renders eight activity-only stat lines (Total turns, Active days, Busiest/First/Last day, Longest/Current streak, Avg per active day) with zero token/cost/model fields (D-04) and no `null`/`NaN` leaks on the empty-stats path
- `run(args)` wires everything together: `listAllTurns({ noCache })` for cross-session enumeration (D-02), a friendly empty-repo message, `shouldColor()`-gated rendering, and an "(N earlier turns outside the N-week window)" disclosure line when the bounded grid excludes older turns (D-03)
- `turn-fixtures.js` gained an additive `opts.ts` parameter on `makeTurn`/`makeUntrackedTurn`, enabling a real cross-session, multi-day integration test that proves D-02 end to end without breaking any existing fixture call site

## Decisions Made

- Factored a shared `cellForLevel(level, useColor)` helper beneath `cell(count, maxCount, useColor)` so the legend (which needs cells at exact levels 0..4, not counts) and the grid (which derives levels from counts via `bucketFor`) never diverge on ANSI emission logic.
- `renderSummary` uses `value || '—'` for nullable day-key fields rather than a ternary against `null` explicitly, since `''` and `0` are not valid day-key values in this domain, keeping the guard simple and correct.
- The "earlier turns" disclosure sums by iterating `dayMap` and comparing lexicographic `'YYYY-MM-DD'` keys against the grid's first non-null date — reusing the same string-comparison safety `computeSummaryStats` already relies on for sorting, rather than parsing to `Date` objects.
- Did not touch `bin/git-turn`'s `COMMANDS` array — confirmed via the phase's own `03.1-03-PLAN.md` that wiring `heatmap` into the dispatcher and writing the human-verification checkpoint for terminal layout is explicitly Plan 03's task, out of this plan's `files_modified` scope.
