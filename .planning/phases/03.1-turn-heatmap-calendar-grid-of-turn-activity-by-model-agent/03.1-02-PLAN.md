<interface_contract>
Added exports (on top of Plan 01's six functions and three constants):

- `densityGlyph(level)` -> one of `' '`, `'.'`, `':'`, `'+'`, `'#'` for levels `0..4`.
- `densityAnsi(level)` -> 256-color palette index: `236, 22, 28, 34, 40` for levels `0..4`.
- `renderGrid(grid, { maxCount, useColor })` -> `string[]` of output lines: one month-label line, then 7 weekday rows, then a legend line.
- `renderSummary(stats)` -> `string[]` of output lines for the activity summary block.
- `run(args)` -> prints to stdout via `console.log`; returns `undefined`. Accepts `--no-cache`.

Cell encoding: colored cell is `\x1b[48;5;{code}m  \x1b[0m` (two spaces, own reset — research Pitfall 3). Uncolored cell is `densityGlyph(level) + ' '`. Weekday label column is exactly `LABEL_WIDTH` (4) characters: `'Sun '`, `'Mon '`, ... rendered only for Mon/Wed/Fri rows, `'    '` for the rest (reference screenshot convention).
</interface_contract>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git refs / SQLite cache -> `run()` | Turn records (including `ts` from commit-message `created` lines) enter the process |
| `run()` -> stdout / pipe | ANSI escapes may reach a non-terminal consumer |
| env (`NO_COLOR`, `FORCE_COLOR`, `process.stdout.columns`) -> render decisions | Environment controls escape emission and grid width |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03.1-04 | Tampering | ANSI escape emission into piped output | mitigate | Every escape gated by `shouldColor()` from `src/git.js`; acceptance criteria assert zero `\x1b` under `NO_COLOR=1` including in the summary block |
| T-03.1-05 | Tampering | Terminal-escape injection via turn metadata | mitigate | `run()` renders only numeric counts and `YYYY-MM-DD` keys derived from `dayKey()`; no `session_id`, branch name, or commit-message text is echoed to stdout, so hostile ref content cannot inject escapes |
| T-03.1-06 | Denial of Service | `process.stdout.columns` extreme/absent values | mitigate | `availableWeeks()` from Plan 01 clamps to `1..53`; verified by Plan 01 acceptance criteria |
| T-03.1-07 | Information Disclosure | Summary block content | accept | Emits only counts and dates, strictly less than `git turn log` already shows; D-04 explicitly excludes token/cost/model data |
| T-03.1-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new dependencies (RESEARCH.md audit skipped for that reason). An `npm install` in this plan is a deviation to reject |
</threat_model>
