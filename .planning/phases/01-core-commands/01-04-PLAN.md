Create src/commands/gc.js.

Imports: 'use strict'. Import listRefs, deleteRef, and gitSafe from '../git'. Import readSession from '../session'.

Define a listSessionsByAge() helper function inside the module (not exported). Implementation:
- prefix = 'refs/git-turn/sessions/'.
- out = gitSafe(['for-each-ref', '--format=%(refname) %(creatordate:iso-strict)', '--sort=creatordate', prefix]).
- If out is null or empty string: return [].
- Parse out: split by newline, filter empty lines. For each line, extract refname (split on first space, take index 0). Extract sessionId: refname.replace(prefix, '').split('/')[0].
- Deduplicate preserving oldest-first order: use a Set and push sessionId only the first time it is seen.
- Return array of sessionId strings, oldest first.

run(args):
1. Parse --keep-sessions: keepIdx = args.indexOf('--keep-sessions'). keepN = keepIdx !== -1 ? parseInt(args[keepIdx + 1], 10) : 10. If --keep-sessions provided but value is NaN: console.error('git turn gc: --keep-sessions requires a number') + process.exit(1).
2. currentSession = readSession(). May be null — gc works without active session.
3. allSessions = listSessionsByAge(). Oldest first.
4. toDelete = allSessions.slice(0, Math.max(0, allSessions.length - keepN)).
5. pruned = 0. For each sessionId in toDelete: if currentSession && sessionId === currentSession.session_id: continue (D-09 — never prune current session). refs = listRefs('refs/git-turn/sessions/' + sessionId + '/'). For each { ref } of refs: deleteRef(ref). pruned += refs.length. console.log('Pruned session ' + sessionId + ' (' + refs.length + ' turns)').
6. If pruned > 0: console.log("Snapshot objects will be reclaimed on next 'git gc'") (D-10 — exact string, single quotes inside the message).

module.exports = { run }.
