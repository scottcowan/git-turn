Create src/commands/revert.js.

Imports: 'use strict'. Import snapshotWorktree and restoreSnapshot from '../git'. Import readSession, listTurns, and writeOp from '../session'.

run(args):
1. Session guard: session = readSession(). If null: console.error('git turn: not initialized. Run `git turn init` first.') + process.exit(1).
2. Parse N: N = parseInt(args[0], 10). If isNaN(N): console.error('Usage: git turn revert <N>') + process.exit(1).
3. turns = listTurns(session.session_id).
4. turn = turns.find(t => t.turn_n === N). If not found: console.error('git turn: turn ' + N + ' not found') + process.exit(1).
5. Pre-revert snapshot (MUST happen before any restore): const { commitSha: preRevertSha } = snapshotWorktree({ message: 'pre-revert snapshot (turn ' + N + ')' }). This captures current worktree so redo can restore it (Pitfall 5 from RESEARCH.md).
6. Write revert op BEFORE calling restoreSnapshot: opHash = writeOp('revert', { session_id: session.session_id, turn_n: N, snapshot_sha: turn.sha, pre_revert_snapshot_sha: preRevertSha, branch: session.branch }). Capture the return value opHash — redo uses it.
7. Restore worktree (D-01): restoreSnapshot(turn.sha, { branch: session.branch }). Let any thrown Error propagate unhandled — this surfaces both the branch mismatch error (D-03) and any unexpected git errors with clear messages.
8. On success: console.log('Reverted to turn ' + N).

module.exports = { run }.

IMPORTANT: step 5 (snapshotWorktree) and step 6 (writeOp) MUST happen before step 7 (restoreSnapshot). If restoreSnapshot throws (D-03 branch mismatch), the op log entry is already written — that is acceptable; the op has pre_revert_snapshot_sha pointing to a valid snapshot of the pre-revert state.

Create src/commands/redo.js.

Imports: 'use strict'. Import restoreSnapshot from '../git'. Import readSession, readOps, and writeOp from '../session'.

run(args):
1. Session guard: session = readSession(). If null: console.error('git turn: not initialized. Run `git turn init` first.') + process.exit(1).
2. ops = readOps(). readOps() returns ascending ts-sorted array — use spread+reverse for LIFO.
3. Build set of already-redeemed revert op hashes: const redeemedHashes = new Set(ops.filter(op => op.type === 'redo').map(op => op.revert_op_hash)).
4. Find last unredeemed revert op (LIFO, D-02): const lastRevert = [...ops].reverse().find(op => op.type === 'revert' && !redeemedHashes.has(op.revert_op_hash)). Note: the revert op's own hash is NOT stored in its payload — use a different matching strategy: since writeOp returns the hash, the redo op stores it as revert_op_hash, but we need the file hash. Alternative approach: match by checking that no redo op's revert_op_hash equals the hash of this specific revert op. Since we cannot recover the hash from the payload alone, use a simpler strategy: find the last revert op where no redo op has a revert_turn_n matching this op's turn_n AND session_id.

  Revised approach for matching: const redeemedKeys = new Set(ops.filter(op => op.type === 'redo').map(op => op.session_id + ':' + op.revert_turn_n)). const lastRevert = [...ops].reverse().find(op => op.type === 'revert' && !redeemedKeys.has(op.session_id + ':' + op.turn_n)).

5. If lastRevert not found: console.error('git turn: nothing to redo') + process.exit(1).
6. Restore worktree: restoreSnapshot(lastRevert.pre_revert_snapshot_sha, { branch: lastRevert.branch }). Let errors propagate.
7. Mark revert as consumed: writeOp('redo', { session_id: session.session_id, revert_turn_n: lastRevert.turn_n, restored_snapshot_sha: lastRevert.pre_revert_snapshot_sha }).
8. console.log('Redo complete (restored state before revert to turn ' + lastRevert.turn_n + ')').

module.exports = { run }.
