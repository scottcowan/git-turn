2. After the line `console.log('✓ Started session: ' + session.session_id)` and before the final console.log about being ready, insert the format blob write block:

   Build schema string: JSON.stringify an object with these exact keys and values: version: '1', tool: 'git-turn', schema: 'turns/v1', ref_pattern: 'refs/git-turn/sessions/{id}/turn-{N}', notes_ref: 'refs/notes/git-turn'.

   Call spawnSync('git', ['hash-object', '-w', '--stdin'], { input: schema, encoding: 'utf8', cwd: process.cwd() }). Check result.status === 0 before proceeding. If status is 0: blobSha = result.stdout.trim(). Call git(['update-ref', 'refs/git-turn/format', blobSha]). Then console.log('✓ Wrote format discovery blob: refs/git-turn/format').

   If result.status !== 0, do not throw — silently skip (init should not fail if blob write fails on unusual git configs).

CRITICAL: ref name MUST be 'refs/git-turn/format' — NOT 'refs/turns/.format' which git rejects (dot-prefixed component is invalid per git check-ref-format rule 5; see RESEARCH.md Pitfall 1).
