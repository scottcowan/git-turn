Create src/commands/diff.js.

Imports: 'use strict'. Import gitSafe from '../git'. Import readSession and listTurns from '../session'. No other imports needed.

Constants: EMPTY_TREE = '4b825dc642cb6eb9a060e54bf8d69288fbee4904' (same constant used in show.js).

run(args):
1. Session guard: readSession(); if null, console.error('git turn: not initialized. Run `git turn init` first.') + process.exit(1).
2. Parse N: N = parseInt(args[0], 10). If isNaN(N): console.error('Usage: git turn diff <N> [M]') + process.exit(1).
3. Parse optional M: if args[1] !== undefined, M = parseInt(args[1], 10). If args[1] defined and isNaN(M): same usage error + exit 1. If args[1] undefined, M = null.
4. turns = listTurns(session.session_id).
5. Define findTurn(n): t = turns.find(t => t.turn_n === n). If not found: console.error('git turn: turn ' + n + ' not found') + process.exit(1). Return t.
6. If M !== null (D-04 — two explicit turns): shaA = findTurn(N).sha, shaB = findTurn(M).sha.
7. If M === null (D-05 — single turn, diff N-1 vs N): shaB = findTurn(N).sha. prevTurn = turns.find(t => t.turn_n === N - 1). shaA = prevTurn ? prevTurn.sha : EMPTY_TREE.
8. Output: out = gitSafe(['diff', shaA, shaB]) || '(no changes)'. console.log(out).

All git args are passed as an array — never as a string with interpolation (e.g., use ['diff', shaA, shaB] not ['diff', shaA + '..' + shaB]).

module.exports = { run }.
  </action>
