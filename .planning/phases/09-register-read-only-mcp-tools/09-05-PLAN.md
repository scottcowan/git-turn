<interfaces>
- bin/git-turn path from src/mcp/tools/: join(__dirname, '..', '..', '..', 'bin', 'git-turn')
- `git turn init` installs .git/hooks/post-commit (a `#!/usr/bin/env node` script requiring src/hooks/post-commit.js) and starts a session; prints progress to stdout.
- post-commit hook writes note on HEAD via addNote(NOTES_REF, head, { session_id, turn_n, snapshot_sha, ts }), updates refs/git-turn/sessions/<id>/turn-<N>, inserts SQLite cache row.
- `git turn record-prompt` reads one JSON object on stdin { prompt, model, usage, latency_ms, tool_summary } and merges into the latest turn's note.
- NOTES_REF = 'refs/notes/git-turn' (src/session.js). readSession() (src/session.js) returns { session_id, turn_n, ... }.
- cost pricing cache: join(HOME, '.git-turn-pricing.json'), shape { _fetched_at: Date.now(), data: { 'claude-sonnet-4-5': { input_cost_per_token: 0.000003, output_cost_per_token: 0.000015 } } }; 1000 in + 500 out -> '$0.0105'.
- Tool handlers: log { withPrompts, noCache }, show { turn, withPrompts }, diff { turn, toTurn }, blame { file, noCache }, cost { all, noCache } — all async, return { content: [{ type: 'text', text }], isError? }.
- renderRich colorless rows format: `<gutter> <marker> <text>` (e.g. `1 + v2`).
</interfaces>
