| T-09-02 | Information disclosure / output corruption | show/diff output under inherited FORCE_COLOR | mitigate | opts.color === false short-circuits before shouldColor() on both --plain and rich branches; tested under FORCE_COLOR=1 for both branches (Pitfall B) |
