<interfaces>
Adapter contract (all 3 files, from PATTERNS.md "Shared Patterns"):
- 'use strict'; const { z } = require('zod'); const { compute } = require('../../commands/<name>');
- async function handler(params) -> CallToolResult: success { content: [{ type: 'text', text }] }; failure { content: [{ type: 'text', text: e.message }], isError: true }
- function register(server) calls server.registerTool('<tool_name>', { description, inputSchema: z.object({...}) }, handler)
- module.exports = { register, handler }
- inputSchema MUST be an explicit z.object({...}) (raw-shape record form is @deprecated in installed @modelcontextprotocol/server 2.3.1)

compute() facts:
- log.compute(args, opts={}) -> string, sync. Flags: --with-prompts, --no-cache. Throws 'git turn: not initialized. Run `git turn init` first.'
- blame.compute(args, opts={}) -> string, sync. File = first arg not starting with '--'. Flags: --no-cache. Throws 'Usage: git turn blame <file> [--no-cache]', 'git turn: no history for <file>', not-initialized message. opts.stderr optional warning sink.
- cost.compute(args, opts={}) -> Promise<string>, ASYNC. Flags: --all, --no-cache. Throws not-initialized message and 'git turn: could not load pricing data: <msg>\nCheck your internet connection or try again later.' opts.stderr optional progress sink. Pricing cache at path.join(os.homedir(), '.git-turn-pricing.json') with shape { _fetched_at, data: { [model]: { input_cost_per_token, output_cost_per_token } } }.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client -> tool handler | Tool arguments arrive as untrusted JSON from whatever process the user configured as an MCP client |
| tool handler -> compute() | Reconstructed argv crosses into the same parsing contract the CLI uses |
| compute() Error -> MCP result | Error text leaves the server as tool content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Tampering | log/blame/cost zod inputSchema | mitigate | Every field typed with a concrete primitive (z.boolean().optional(), z.string().min(1)); never z.any(); SDK rejects mismatched args before the handler runs, so a non-string file can never reach blame's .startsWith (Pitfall C) |
| T-09-05 | Denial of service | handler exceptions | mitigate | try/catch around every compute() call returns isError instead of throwing; no run()/process.exit reachable (grep acceptance criteria); tested for uninitialized-repo and command-specific errors |
| T-09-06 | Information disclosure | error text (e.g. 'git turn: no history for <file>', pricing failure message) | accept | Text is identical to what the CLI prints to the same local user; the MCP client runs with the user's own privileges against the user's own repo, so no new audience is exposed |
| T-09-07 | Information disclosure | blame file argument (path outside repo, e.g. '../x') | accept | blame.compute() resolves through git in the server's repo scope with the same behavior and privileges as `git turn blame <file>`; no new capability beyond the CLI |
| T-09-08 | Spoofing / Tampering | cost pricing fetch | accept | Unchanged cost.js behavior (HTTPS fetch of LiteLLM pricing, cached); tests stub https and redirect HOME so CI never hits the network |
</threat_model>
