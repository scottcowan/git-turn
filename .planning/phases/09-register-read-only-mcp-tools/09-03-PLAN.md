## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-09 | Tampering | show/diff zod schemas | mitigate | turn/toTurn are z.number().int().positive(); non-numeric or fractional input is rejected by the SDK before the handler runs; String() coercion only on validated integers |
| T-09-10 | Information disclosure / output corruption | ANSI leakage into MCP text content | mitigate | Adapters pass { color: false } unconditionally and contain no env/TTY checks (grep criterion); tests run handlers under FORCE_COLOR=1 |
| T-09-11 | Denial of service | thrown errors from compute() | mitigate | try/catch -> isError; tested for out-of-range turn (both N and M) and uninitialized repo |
| T-09-12 | Information disclosure | prompt text via withPrompts | accept | Prompt is only included when the caller explicitly passes withPrompts, identical to the CLI flag; prompts are already redacted on capture by record-prompt; same local-user trust domain |
</threat_model>
