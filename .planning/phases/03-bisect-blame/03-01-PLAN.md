## Normalized turn shape (contract for all of Phase 3)

Every function that returns turns in this plan MUST return objects with these keys, whether sourced from the SQLite cache or from a ref walk:

`{ session_id, turn_n, snapshot_sha, head_sha, branch, ts }`

- `session_id` — string UUID (cache column `session_id`; ref path segment in the fallback)
- `turn_n` — number (cache column `turn_n`; `turn-<N>` ref suffix in the fallback)
- `snapshot_sha` — string, the dangling snapshot commit (cache column `snapshot_sha`; `%(objectname)` in the fallback)
- `head_sha` — string or null, the REAL commit that was HEAD when the snapshot was taken (cache column `head_sha`; parsed from the snapshot commit message `head ` line in the fallback)
- `branch` — string or null (cache column `branch`; snapshot message `branch ` line in the fallback)
- `ts` — ISO string (cache column `ts`; snapshot message `created ` line in the fallback, defaulting to `new Date(0).toISOString()`)

Cache rows already satisfy this shape as-is — do NOT rename or remap cache columns. The ref-walk fallback must be built up to match it.

## src/blame-util.js exports (exact signatures)

- `listAllTurns({ noCache = false } = {})` -> `Turn[]`
- `listAllTurnsFromRefs()` -> `Turn[]`
- `buildHeadShaIndex(turns)` -> `{ index: Map<string, Turn>, collisions: string[] }`
- `orderByCommitTopology(turns)` -> `Turn[]`
- `isAncestor(sha, rev = 'HEAD')` -> `boolean`
- `parseHunkHeader(line)` -> `{ oldStart, oldCount, newStart, newCount } | null`
- `parseBlamePorcelain(text)` -> `Array<{ sha, line_no, content }>`
- `annotateFromSnapshots(file, turns)` -> `Array<{ line_no, content, turn }>` where `turn` is a Turn or null
