<interfaces>
PHASE-WIDE compute/run CONTRACT (identical in Plans 07-02, 07-03, 07-04 — do not deviate):

- Signature: `compute(args, opts = {})`. `args` is the same argv array `run()` receives. `opts.stderr` is an optional `(chunk: string) => void` sink; when absent, compute() performs NO writes of any kind. compute() never references `console`, `process.exit`, `process.stdout`, or `process.stderr`.
- compute() returns ONE string. For text mode it is the exact bytes the old run() printed, minus the final trailing newline: build a `lines` array where each old `console.log(x)` becomes `lines.push(x)` with the IDENTICAL string `x` (embedded '\n' characters kept as-is, e.g. `lines.push(`Session: ${session.session_id}\n`)`), and `return lines.join('\n')`. This is byte-identical by construction because `console.log` appends one '\n'.
- Every old `console.error(msg); process.exit(1)` becomes `throw new Error(msg)` with the identical message string. Multi-line errors join lines with '\n'.
- Every old direct `process.stderr.write(s)` becomes `if (opts.stderr) opts.stderr(s)` at the same point in control flow with the identical string `s`.
- `--json` is detected with `args.includes('--json')`; JSON output is always produced by `JSON.stringify(<object>)` (compact, no indentation), never hand-concatenated.
- run() shape (sync commands): `function run(args) { try { console.log(compute(args, { stderr: (s) => process.stderr.write(s) })); } catch (e) { if (args.includes('--json')) { console.log(JSON.stringify({ error: e.message })); process.exit(1); return; } console.error(e.message); process.exit(1); } }`. The `return` after `process.exit(1)` guards test stubs that do not throw.
- `module.exports = { run, compute }`.
- Existing pre-phase test cases in each *.test.js MUST NOT be edited (REFACTOR-01 / ROADMAP SC2). New test cases are appended only. Baseline for the additions-only check is commit `98679b8` (last commit before Phase 7 planning; no Phase 7 docs commit touches src/).

Existing helpers (unchanged): `parseSnapshotMessage(sha) -> { headSha, ... }` (src/blame-util.js lines 28-37); `blameUtil.listAllTurns({noCache})`, `buildHeadShaIndex(turns) -> {index: Map<head_sha, turn>, collisions: string[]}`, `parseBlamePorcelain(text) -> [{sha, line_no, content}]`, `orderByCommitTopology(turns)`, `annotateFromSnapshots(file, turns) -> [{line_no, content, turn|null}]`; cache rows from `getTurns()` carry `turn_n, snapshot_sha, head_sha, files_changed, insertions, deletions, prompt, model, latency_ms, ts`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Tampering (injection) | blame file argument | mitigate | File path continues to reach git only via `gitSafe([...,'--', file])` argv arrays (execFileSync, no shell); the `--` separator stays in place for ls-files and blame. No new git invocations take user strings. |
| T-07-06 | Tampering (output integrity) | --json serialization | mitigate | All JSON (success and `{error}`) built with `JSON.stringify` on real objects, so commit subjects/prompts/file contents containing quotes, newlines or control characters are escaped and cannot break a consumer's parse. |
| T-07-07 | Information disclosure | log --json prompt field | mitigate | `prompt` key emitted only when `--with-prompts` is passed, same gate as text mode; prompts are already redacted at capture by record-prompt. |
| T-07-08 | Denial of Service (host process) | compute() reachable code | mitigate | No `process.exit`/`console`/stderr writes inside compute(); verified by slice-check acceptance criteria, so an in-process MCP host cannot be killed or have its stdio corrupted. |
| T-07-09 | Input validation (V5) | flag parsing | accept | Flags are exact `args.includes(...)` string matches; unknown flags ignored exactly as today. |
