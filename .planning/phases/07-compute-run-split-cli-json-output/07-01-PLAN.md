<feature>
  <name>Rich unified-diff renderer (DIFF-01)</name>
  <files>src/diff-render.js, src/diff-render.test.js</files>
  <behavior>
    Parsing rules for parseDiff (state machine, NOT prefix-sniffing of '---'/'+++' inside hunks):
    - A line starting with `diff --git ` opens a new file `{ header: line, meta: [], hunks: [] }`.
    - A line for which `parseHunkHeader(line)` is non-null opens a new hunk on the current file and sets `newLine = hunk.newStart`.
    - Lines after a file header and before its first hunk are file-metadata: lines starting with `index `, `--- `, or `+++ ` are discarded; all others (e.g. `new file mode 100644`, `deleted file mode 100644`, `rename from x`, `rename to y`, `Binary files a/x and b/x differ`) are pushed onto `meta`.
    - Once a hunk is open, classify by first character only: `+` → `{type:'add', newLineNo:newLine, text:line.slice(1)}` then `newLine++`, `added++`; `-` → `{type:'del', newLineNo:null, text:line.slice(1)}`, `removed++`; ` ` → `{type:'ctx', newLineNo:newLine, text:line.slice(1)}` then `newLine++`; exactly-empty line → ctx with text '' (then `newLine++`); `\` (e.g. `\ No newline at end of file`) → dropped, not counted.
    - Input null/undefined/'' → `{ files: [], added: 0, removed: 0 }`.

    Rendering rules for renderRich (row text is identical with and without color — color only wraps):
    - Line 1: `Added ${added} / removed ${removed}`; line 2: empty string.
    - If `files.length === 0`: line 3 is `(no changes)` and nothing else follows.
    - Gutter width G = number of digits of the largest `newLineNo` across all rows (minimum 1).
    - For each file (a blank line separates consecutive files, none before the first): file header line, then each meta line, then for each hunk: the hunk header line, then each content row as `${gutter} ${marker} ${text}` where gutter = `String(newLineNo).padStart(G)` or `' '.repeat(G)` when newLineNo is null, and marker is `+`, `-`, or a single space for add/del/ctx.
    - color=false: no byte `\x1b` anywhere in the output.
    - color=true: file header, meta and hunk header lines become `\x1b[2m` + line + `\x1b[0m`; add rows become `\x1b[48;5;22m` + row padded with spaces to `width` (no truncation if longer) + `\x1b[0m`; del rows the same with `\x1b[48;5;52m`; ctx rows become `\x1b[2m` + gutter + `\x1b[0m` + ` ${marker} ${text}`; the summary line and `(no changes)` are unstyled.

    Test cases (input -> expected):
    - Single-file SAMPLE (`diff --git a/foo.txt b/foo.txt`, `index 0000000..1111111 100644`, `--- a/foo.txt`, `+++ b/foo.txt`, `@@ -1,2 +1,2 @@`, ` context line`, `-removed line`, `+added line`) -> parseDiff added=1 removed=1; files[0].hunks[0].lines types ['ctx','del','add'] with newLineNo [1,null,2]; files[0].meta is [] (index/---/+++ dropped).
    - renderRich(SAMPLE,{color:false}) split on '\n' -> [0]==='Added 1 / removed 1', [1]==='', contains row '1   context line', row '  - removed line', row '2 + added line'; no '\x1b'.
    - renderRich(SAMPLE,{color:true,width:40}) -> contains '\x1b[48;5;22m' and '\x1b[48;5;52m'; the add row equals '\x1b[48;5;22m' + '2 + added line'.padEnd(40) + '\x1b[0m'.
    - Hunk containing raw line `--- sql comment` after `@@ -1,1 +1,1 @@` -> removed===1 and the del row text is '-- sql comment'.
    - Hunk containing raw line `+++ plus` after a hunk header -> added===1.
    - `\ No newline at end of file` inside a hunk -> not counted, not rendered.
    - Two-file diff -> files.length===2, counts summed, exactly one blank line between the first file's last row and the second `diff --git` line.
    - New-file diff with `new file mode 100644` and `@@ -0,0 +1,3 @@` + three `+` lines -> meta ['new file mode 100644'], gutter numbers 1,2,3.
    - Binary diff (`diff --git a/x.png b/x.png`, `Binary files a/x.png and b/x.png differ`) -> added=0 removed=0, meta contains the Binary line, renderRich output contains it.
    - Gutter width: a hunk starting at `+98,4` producing line numbers 98..101 -> rows' gutters are 3 chars wide ('98' rendered as ' 98').
    - renderRich('') and renderRich(null) -> exactly 'Added 0 / removed 0\n\n(no changes)'.
    - EMPTY_TREE === '4b825dc642cb6eb9a060e54bf8d69288fbee4904'.
  </behavior>
  <implementation>Module follows src/blame-util.js conventions: 'use strict', plain functions, flat named exports. RESEARCH.md Pattern 3 (lines ~206-289 of 07-RESEARCH.md) is the starting draft but MUST be corrected per the behavior above: (1) keep the +/-/space marker in every row so colorless output still distinguishes rows (D-03 — the draft drops it), (2) classify by state machine so '---'/'+++'-prefixed content lines inside a hunk are counted, (3) take width via opts instead of reading process.stdout.columns, (4) preserve non-index file metadata lines.</implementation>
</feature>
