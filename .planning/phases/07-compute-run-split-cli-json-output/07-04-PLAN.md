## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-14 | Tampering (injection) | turn-number args | mitigate | Turn numbers still parsed with `parseInt(…,10)` + `isNaN` guard; only resolved snapshot SHAs from `listTurns()` (never raw argv) reach `gitSafe(['diff', …])` argv arrays (execFileSync, no shell). Positional filter strips only the exact strings `--json`/`--plain`. |
| T-07-15 | Tampering (output integrity) | --json | mitigate | `JSON.stringify` on real objects; diff text in JSON is always fetched with `--color=never` so no ANSI bytes leak into JSON consumers. |
| T-07-16 | Tampering (terminal escape injection) | rich/plain render | accept | Same exposure as today's git diff passthrough; renderer adds only fixed escape constants (see T-07-01). |
| T-07-17 | Information disclosure | show --json prompt | mitigate | `prompt` key only when `--with-prompts` is passed, matching the text gate; prompts are redacted at capture. |
| T-07-18 | Denial of Service (host process) | compute() | mitigate | No `process.exit`/console/stderr in compute() (slice-check criteria); the only process access is the read-only `process.stdout.columns` width lookup. |
