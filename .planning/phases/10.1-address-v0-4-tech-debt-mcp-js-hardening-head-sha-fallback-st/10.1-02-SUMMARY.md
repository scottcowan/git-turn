# Phase 10.1 Plan 02: cost.js head fallback and arithmetic hardening Summary

`git turn cost` no longer falls back to the snapshot sha for note lookup (both `--all` and single-session paths), and malformed usage can no longer produce NaN totals.

## Tasks

1. Null head instead of snapshot-sha fallback (commit 1557491). Tests planting a note on the snapshot sha failed first (RED), pass after.
2. `computeCost` returns null on non-finite usage fields; `?` shown in token columns for bad fields; display strip regex is `/i`; `fetchPricing` rejects on non-200 and is now exported (commit following 1557491).

## Deviations from Plan

- [Rule 3] The D-03 stderr and fetchPricing tests use manual monkeypatching of `process.stderr.write` / `https.get` instead of `node:test` `mock.method`, because `mock.method` caused the test run to hang in this environment.
- `fetchPricing` added to module exports (additive, anticipated by the plan).
