## Summary

All work is localized edits to existing files with existing test files beside them. No new dependencies, so no package legitimacy audit is needed. The only non-trivial design point is testing the two new mcp.js behaviors (hung `close()`, throwing `serveStdio`), and two existing static tests in `mcp.test.js` that the mcp.js changes will break.

Biggest planning trap: `mcp.test.js` test "no process.exit reachable after serveStdio (Pitfall 3)" (lines 292-305) asserts the LAST `process.exit` in comment-stripped mcp.js precedes the first `serveStdio(`. D-04 (`process.exit(0)` in SIGINT timer) and D-05 (`process.exit(1)` in catch) both necessarily sit after/around `serveStdio(`. That test must be rewritten in the same plan as the mcp.js change (intent: no `process.exit` on the normal request path / not reachable from `src/mcp/`; the server.js half of the assertion stays valid). The "cwd captured exactly once" test counts `process.cwd()` occurrences in non-comment lines: keep exactly one; the D-07 comment fix must not add a non-comment `process.cwd()`. Note the strip helper drops only whole-line `//` comments, so a trailing `// ...process.exit` comment on a code line would be counted.

**Primary recommendation:** Three small waves/plans: (1) mcp.js + bin help + its tests (rewrite Pitfall-3 test), (2) cost.js head fallback + NaN guard + tests, (3) Phase 7/9 sweep (diff-render, blame-util, adapters, show.js) + bookkeeping edits. Plans 1-3 touch disjoint files except `cost.js` (plan 2 only), so they can run in parallel.

## Common Pitfalls

1. **Pitfall-3 static test breaks** (see Summary). Rewrite, don't delete: assert `src/mcp/**` has no `process.exit`/`process.on`, and that mcp.js's `process.exit` calls are only (a) before serveStdio (not-initialized), (b) in the serveStdio catch, (c) inside the SIGINT timer callback.
2. **Test-process hazards**: calling `run()` in-process with real `process.exit` kills the test runner. Stub `process.exit` (`mock.method(process, 'exit', ...)`) and `process.once` SIGINT registration (capture the handler via `mock.method(process, 'once', ...)`), never emit a real SIGINT in the runner. Also `process.exit` stub must throw or `return` carefully: mcp.js has `return` after exit, so a no-throw stub is fine.
3. **mcp.test.js runs in its own pass** (`npm test` excludes it from the first `node --test` and runs it second) because it spawns subprocesses with long timeouts. Put new mcp.js tests there. In-process tests with `process.chdir` + `HOME` swap follow the existing beforeEach/afterEach.
4. **Do not log in startup-failure path to stdout**; stdout is JSON-RPC only.
5. **cost `--json` null fields**: `jsonTurns` entry for an unresolved-head turn must have `model: null`, null token fields, `cost: null` -- already so via `usage ? ... : null`.
6. **Regression test for D-01 must prove "never reads a note keyed by snapshot sha"**: seed a note on the SNAPSHOT sha with model+usage and a priced fixture; make a turn whose snapshot message lacks the `head` line (or null `head_sha` via cache); assert report shows `(no model recorded)`/`?` and `turns_with_model: 0`. Without the fix this test sees the planted note. Build such a snapshot by hand: `snapshotWorktree({ message: 'turn 1\nsession X\nturn_n 1' })` + `updateRef(turnRef(...))` + `incrementTurn` (helpers in `src/git.js`, `src/session.js`; `makeTurn` always writes `head`). Add a variant with `--all` (use `--no-cache` or ensure cache rebuilt) and the single-session path.
7. `process.exit` inside `.finally` of SIGINT: do not call `process.exit` from the normal close path; natural exit relies on `stdin.destroy()` (existing test 'exits cleanly on SIGINT' guards this, expecting code 0 and stderr exactly the one startup line -- do not emit extra stderr on SIGINT).

### In-process test of startup throw (D-05) and hung close (D-04)
```js
const Module = require('module');
function loadMcpWithFakeServe(fakeServeStdio) {
  const origLoad = Module._load;
  Module._load = function (request, ...rest) {
    if (request === '@modelcontextprotocol/server/stdio') return { serveStdio: fakeServeStdio };
    return origLoad.call(this, request, ...rest);
  };
  try {
    delete require.cache[require.resolve('./mcp')];
    return require('./mcp');
  } finally { Module._load = origLoad; }
}

test('serveStdio throw -> "git turn: <msg>" on stderr, exit 1, no stack', () => {
  require('../helpers/turn-fixtures').startSession();          // readSession() must succeed
  const { run } = loadMcpWithFakeServe(() => { throw new Error('boom'); });
  const exit = mock.method(process, 'exit', () => {});
  const err = mock.method(process.stderr, 'write', () => true);
  try { run([]); } finally { exit.mock.restore(); err.mock.restore(); }
  assert.deepEqual(exit.mock.calls.map(c => c.arguments[0]), [1]);
  assert.equal(err.mock.calls[0].arguments[0], 'git turn: boom\n');
  assert.equal(err.mock.calls.length, 1);
});

test('SIGINT with never-settling close() force-exits 0 after ~2s', () => {
  require('../helpers/turn-fixtures').startSession();
  mock.timers.enable({ apis: ['setTimeout'] });
  let sigint; const once = mock.method(process, 'once', (ev, fn) => { if (ev === 'SIGINT') sigint = fn; });
  const exit = mock.method(process, 'exit', () => {});
  mock.method(process.stderr, 'write', () => true);
  const { run } = loadMcpWithFakeServe(() => ({ close: () => new Promise(() => {}) }));
  run([]); sigint();
  mock.timers.tick(1999); assert.equal(exit.mock.calls.length, 0);
  mock.timers.tick(1);    assert.deepEqual(exit.mock.calls.map(c => c.arguments[0]), [0]);
  mock.restoreAll(); mock.timers.reset();
});
```

Confirm that the mocked `setTimeout` returns an object with `.unref()`; node's MockTimers returns a Timeout-like object with `unref` -- verify in the first test run, fall back to a manual `global.setTimeout` stub if not.)

Optional black-box alternative: spawn with `NODE_OPTIONS=--require <preload.js>` that wraps `serveStdio` to return a never-settling `close`; since `serveStdio` is a writable property on the CJS exports, the patch works, but the real test takes >=2s wall time.
