## Advisory observations (non-blocking, from 10.1-REVIEW.md)

None of these contradict a locked decision.

- **WR-01:** `formatToolSummary` and the model/latency lines do not strip ESC or other control characters. This goes beyond D-10, which only covers delimiter collision.
- **WR-02:** `isTokenCount` accepts negative numbers, so a malformed note can produce a negative cost. D-09 only required NaN protection.
- **WR-03:** Only SIGINT is handled, not SIGTERM. The force-exit exits 0 as D-04 specifies, which is the locked contract.
- **WR-04:** MCP tool turn validation allows 0 and negatives in some adapters. The `blame` tool's `file` is not checked for a leading `-`. The git call is `show sha:file`, so argument injection is unlikely, but this is unconfirmed.
- **IN-01/IN-02:** An over-long comment in `cost.js`, and the silent behavior change for unresolved heads. The latter is intended by D-03.
