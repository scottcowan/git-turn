<decisions>
## Implementation Decisions

### head_sha fallback (cost.js)
- **D-01:** When a turn's head commit cannot be resolved, do NOT use `snapshot_sha` as a notes key. Skip the note lookup but keep the turn in the report (no model/usage, zero cost, still counted in turn totals).
- **D-02:** Apply at both sites: `cost.js:194` (`--all` path, `t.head_sha || t.snapshot_sha`) and `cost.js:~255` (single-session path, `headSha || sha`). `renderSession` must tolerate a null/absent `head`.
- **D-03:** No stderr warning (output stays clean for `--json`/MCP).

### mcp.js SIGINT shutdown
- **D-04:** If `handle.close()` has not settled within ~2s of SIGINT, force `process.exit(0)` via an unref'd timer. Exit code stays 0 (AGENTS.md contract: "Exits 0 silently ... on SIGINT").

### mcp.js startup error handling
- **D-05:** Wrap `serveStdio(createServer)` in try/catch; on throw print `git turn: <message>` to stderr, exit 1, no stack trace. Matches CLI-wide convention.

### Cosmetic + bookkeeping
- **D-06:** `bin/git-turn:37` help text: drop "(no tools yet)".
- **D-07:** Fix stale comment at `src/commands/mcp.js:20` (handlers rely on unchanged process cwd, not a passed `repoPath`).
- **D-08:** Set `08-VERIFICATION.md` frontmatter status to reflect closure by `10-HUMAN-UAT.md`; fill `09-01-SUMMARY.md` `requirements-completed`.

### Extra debt pulled in (all selected)
- **D-09 (Phase 7):** WR-01 validate `usage` fields so NaN can't poison cost totals; WR-03 `renderRich()` gutter width without array spread (no RangeError); WR-04 `annotateFromSnapshots()` build `sha:path` safely for colon filenames. Related lower-priority: WR-02 case-insensitive model-prefix strip, IN-01..03 (blame `--` filenames, dead `line === ''` branch, `fetchPricing()` HTTP status) — planner's discretion to include.
- **D-10 (Phase 8/9):** Phase 9 WR-01 adapter `handler()` direct-call guard; tool_summary delimiter-collision guard. Phase 8/9 IN items at planner's discretion.

### Claude's Discretion
