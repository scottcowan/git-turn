Algorithm, exactly as specified in 05-RESEARCH.md Focus Question 1: loop `for (let attempt = 0; attempt <= maxRetries; attempt++)`; read `before = getNote(ref, commitSha)`; derive `existing` by `JSON.parse(before)` inside try/catch falling back to `{}` (and `{}` when `before` is falsy); compute `patched = patchFn(existing)` and `patchedJSON = JSON.stringify(patched)`; re-read `justBeforeWrite = getNote(ref, commitSha)`; if it strictly differs from `before`, either throw `new Error(\`updateNote: note for ${commitSha} changed concurrently, giving up after ${maxRetries} retries\`)` when `attempt === maxRetries`, or `continue`; otherwise `addNote(ref, commitSha, patchedJSON)` and `return patched`.
