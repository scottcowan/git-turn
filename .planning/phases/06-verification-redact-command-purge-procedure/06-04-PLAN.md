| Boundary | Description |
|----------|-------------|

| refs/notes/git-turn history → object store reachability | The ancestor chain is what keeps a leaked blob alive; collapsing it is the security-relevant action |
| documentation → user's mental model | A user who believes a secret is purged when it is not is worse off than one who knows it is still present |
