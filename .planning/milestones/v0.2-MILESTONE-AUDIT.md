## Integration Check

Run by `gsd-integration-checker` during this audit cycle.

- Cross-phase wiring: confirmed (cache → blame/bisect → heatmap all read the same session/turn data model consistently)
- E2E flow: confirmed working (init → commits → log/show/diff/blame/bisect/heatmap)
- **BLOCKER found**: `git turn log --no-cache` and `git turn show <N>` displayed the wrong commit. Root cause: `refs/notes/git-turn` note payload never included a `head` field (only `session_id, turn_n, snapshot_sha, ts`); both commands read `meta.head || sha`, which always fell through to the snapshot sha instead of the real HEAD commit.
  - **Fixed**: commit `a7b41fa`. Extracted `parseSnapshotMessage()` from `blame-util.js` (already-correct logic reading `head`/`branch`/`created` out of the snapshot commit's own message body) and used it in `log.js` and `show.js` instead of relying on the notes payload.
- **WARNING found**: first turn of a session leaked `fatal: ambiguous argument 'refs/.../turn-0'` to stderr from an unguarded `rev-parse` in `post-commit.js`.
  - **Fixed**: same commit. Guarded to skip the rev-parse entirely when `turnN <= 1`.
- Re-verified after fix: full test suite 145/145 passing.
